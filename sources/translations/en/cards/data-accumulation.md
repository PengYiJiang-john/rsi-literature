# Data accumulation: why retaining history changes self-training error

Should each generation replace its data with newly generated samples, or retain data from earlier generations? Gerstgrasser and colleagues change this training protocol to study how errors propagate in [model collapse](model-collapse.md).

## How history constrains later errors

Under replacement, each new model depends only on data generated by its predecessor. A generation's bias enters the entire new dataset, while earlier information no longer participates directly in fitting. Accumulation retains the original data and adds samples from each generation, keeping later models constrained by that history.

The paper compares the protocols exactly in linear regression. The original dataset has T samples with d-dimensional inputs. Each generation reuses their design matrix and generates new outputs, adding independent Gaussian noise with variance σ². The following formula assumes isotropic Gaussian inputs, a full-column-rank design matrix, and T ≥ d+2.

Writing C = σ²d/(T−d−1), the expected excess test mean-squared error due to model estimation at generation n is:

```math
E_{\mathrm{replace}}(n)=Cn,
\qquad
E_{\mathrm{accumulate}}(n)=C\sum_{i=1}^{n}i^{-2}.
```

Replacement adds an error contribution of the same order at each generation, so error grows with the number of generations. Under accumulation, later contributions receive diminishing weights, and their sum has a finite upper bound. Retaining history bounds the error rather than driving it to zero.

## Comparisons in deep models

The authors compare replacement and accumulation in language, molecular, and image generation. Language models are initialized afresh at each generation. A further replacement baseline increases dataset size across generations, testing whether gains merely reflect access to more samples.

Accumulation mitigates degradation in several tasks, although image variational autoencoders can still lose detail. It also uses more samples and gradient steps. The language experiments use model-generated TinyStories as the original reference corpus: “original” here means the data retained from the start of the cycle.

## Memory in the feedback process

Accumulation makes existing information less vulnerable to being overwritten by later errors. For RSI, it addresses how past learning is preserved; new feedback, representation expansion, and update rules determine what can be learned next.
