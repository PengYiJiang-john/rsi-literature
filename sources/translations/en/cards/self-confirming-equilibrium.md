# Self-confirming equilibrium: why accurate feedback can leave mistaken beliefs intact

Real feedback can correct errors that become visible, while leaving unchosen alternatives untested. Fudenberg and Levine use *self-confirming equilibrium* to describe a state in which an agent predicts the consequences of its own behavior correctly, yet may choose an inferior action because it misunderstands the alternatives.

## How an untried option stays undervalued

Consider an illustrative example. A seller expects a new product to fail and therefore sells only the old product. The seller accurately predicts sales of the old product but never obtains sales data for the new one. The new product might be more profitable, yet the feedback received each day cannot reveal this.

Two conditions hold: the old product is best under the seller's beliefs, and those beliefs correctly explain observed sales. Behavior follows the seller's judgment, and observations give no reason to revise it.

Self-confirmation can therefore occur without exaggerating current returns. Errors about untried options allow accurate predictions along the chosen path to coexist with inferior decisions.

## From the example to the definition

The paper studies finite extensive-form games, which describe the sequence of actions and allow players to observe only part of the history. A player's plan determines which situations it actually encounters. The definition requires an adopted strategy to be optimal under some belief, with that belief correct at the information sets actually reached. An information set groups decision situations that the player cannot distinguish from its observations; unreached information sets face no equivalent test.

Different pure strategies played with positive probability may be supported by different beliefs. The definition describes how behavior and observed feedback sustain one another. Whether learning converges to such a state is a separate question.

## How errors escape testing

Beliefs lead an agent to avoid certain actions, and those actions then produce no counterevidence. Correction depends on which feedback has a chance to appear.

[Berk–Nash equilibrium](berk-nash.md) also handles model misspecification: every model an agent considers may omit a regularity, so even observed data can be explained only approximately. For RSI, exploration changes the evidence available; expanding the model class changes the explanations available.
