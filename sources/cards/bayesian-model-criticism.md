# 模型批判为什么不能由后验更新代替

如果只允许用直线解释数据，调整斜率和截距可以找到更好的直线，却不会自动得到一条曲线。这个示意说明了 Gelman 与 Shalizi 强调的区别：在现有模型里选择参数，与发现现有模型不够用，是两种不同工作。

## 后验更新是在既定解释之间重新分配信任

设 D 是已经观察到的数据，θ 是模型参数。贝叶斯更新把原先的参数概率与各参数解释数据的能力结合起来：

```math
p(\theta\mid D)\propto p(D\mid\theta)\,p(\theta).
```

p(θ) 是观察数据前的判断；p(D|θ) 衡量参数为 θ 时这批数据出现的可能性；p(θ|D) 是看完数据后的判断。符号 ∝ 表示两边只差一个使总概率为一的归一化常数。

这一步始终在既定模型内比较。若模型遗漏了关键变量或关系，数据越多，后验可能越集中于其中最合适的参数，但集中本身没有检验模型集合是否足够。直线例子中，越来越确定一条斜率，并不能消除数据里仍然存在的弯曲规律。

## 预测检验问的是模型有没有遗漏

模型批判先问：如果当前模型成立，数据应当表现出什么特点？再比较模型预测与实际观测，寻找有规律的差别。例如，预测误差如果随输入呈现系统变化，就提示模型可能漏掉了某种关系，而不只是参数还没有估准。

发现差别后，研究者可以重新选择变量、修改函数形式，或改变数据生成假设，然后重新拟合并检验。后验计算在当前模型里学习，预测检验和模型修订则改变接下来允许怎样解释数据。

## 为什么这与自我改进的反馈选择有关

[Memento 3](memento-3.md) 把经验写成可修改规则，呈现了类似问题：新反馈可能只要求调整已有规则，也可能迫使系统改写规则本身。

检验能够发现哪些错误，还取决于拿到了什么数据。两个模型可能对已有经历作出同样预测，却对未尝试的行动给出不同结果。若系统一直依据其中一个模型选行动，就可能始终接触不到区分两者的证据。因此，模型修订既要利用已有反例，也需要能暴露反例的行动。
