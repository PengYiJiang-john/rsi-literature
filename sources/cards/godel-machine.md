# Gödel machine 怎样接受一次自修改

找到一个可能有用的修改后，程序应该立即采用，还是继续搜索更好的方案？Gödel machine 用证明条件决定何时停止搜索并修改自身。

## 自修改的接受条件

系统用公理描述自身运行、环境及效用目标。证明搜索程序寻找候选修改，并尝试证明：立即执行修改的预期未来效用，高于继续运行当前搜索过程。

找到证明后，系统执行修改。可替换的部分包括搜索修改和证明的程序，因此一次修改能够改变以后怎样提出、检查和实施下一次修改。

## 为什么比较对象是继续搜索

继续搜索包含以后发现其他方案的可能性。只把候选修改与“永远保持当前程序不变”比较，无法回答为什么不再找一会儿。这里的接受条件把等待、搜索及未来自修改都计入判断，使停止搜索与接受修改成为同一个效用问题。

最优性结果相对于系统的公理成立。实际有效的修改可能无法在其中证明，存在的证明也可能未被及时找到；因此结果约束的是获得证明后的修改选择。

## 证明接受与实验接受

[元决策论](metareasoning.md)同样把计算成本与最终选择联系起来；Gödel machine 还允许改变计算程序自身。现代奖励设计系统 [Eureka](eureka.md)则训练使用候选奖励的策略，以任务表现决定怎样继续修改。前者以证明接受修改，后者以训练实验评价候选，分别提供了自修改的形式化标准与可运行的反馈过程。
