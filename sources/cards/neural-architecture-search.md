# 架构搜索怎样学习提出更好的模型

随机尝试许多结构，也可能找到好网络。Zoph 与 Le 训练一个架构控制器，检验已有候选的训练反馈能否帮助它提出更好的下一批网络。

## 控制器怎样利用候选的表现

控制器生成描述网络结构的符号，例如层的设置或循环单元的连接方式。系统据此建立候选网络，训练其权重，再用验证集评价。控制器把评价作为奖励，通过强化学习调整以后生成不同结构的概率。

每轮因此有两种学习：候选网络学会任务，控制器学习提出网络。前者更新权重，后者更新结构的提案分布。

## 随机搜索对照支持什么

作者在图像分类中搜索卷积结构，在语言建模中搜索循环单元。语言建模实验将控制器搜索与随机搜索比较，既看最佳候选，也看排名靠前候选的平均表现。

控制器在这些比较中优于随机搜索，支持训练反馈能够改善后续提案。多个较好候选的表现提供了超出单个最佳结果的证据；它不要求每次提出的结构都优于上一次。

## 结构搜索与更新规则

控制器在设计者规定的搜索空间中学习；其自身结构与更新算法保持固定。[学习型优化器](learned-optimizers.md)改变怎样训练给定模型，架构搜索改变提出什么模型。两者都把产生任务能力的一个环节，变成可以从经验中学习的机制。
