# 压缩进展 用刚学会的规律选择下一段经验

反复观察已经掌握的规律，通常学不到多少新东西；观看纯噪声，又可能永远找不到规律。学习者应在两者之间寻找什么？Schmidhuber 的回答是：寻找能让自己取得学习进展的经验，并用压缩改善来衡量这种进展。

## 压缩改善怎样表示学会了规律

一个压缩器如果找到了数据中的规律，就可以用“规律加例外”的方式描述它，少记一些逐项内容。因此，可以比较同一段历史在学习前后需要多少编码。

设 h 是固定的一份历史，C旧 与 C新 分别是更新前后的压缩器，L(C,h) 是压缩器 C 描述 h 所需的编码代价。进展奖励可写为：

```math
r_{\mathrm{progress}}
=L(C_{\mathrm{old}},h)-L(C_{\mathrm{new}},h).
```

差值为正，表示新压缩器用更少代价描述了同一批经历。比较必须使用同一份历史：若旧压缩器处理难数据、新压缩器处理容易数据，代价下降就未必来自学习。

## 把学习进展变成下一次行动的理由

系统把这个奖励交给选择行动的控制器。控制器尝试选择可能带来压缩改善的经验；压缩器吸收经验后，实际改善又成为控制器的反馈。于是，学习结果会影响以后去哪里、观察什么，而后续观察继续改变学习结果。

已经熟悉的数据虽然容易压缩，却可能不再带来进展。纯噪声虽然不断变化，也通常无法提供稳定的可复用规律。进展奖励因此希望把行动引向当前尚未掌握、但有希望学会的内容。

进展相对于当前学习器：压缩器训练失败或表达能力不足时，有结构的数据也可能没有进展信号。奖励测量的是观察到的前后变化。

## 它与其他学习量有什么区别

[可用信息](usable-information.md)问观察输入能使某类模型的预测改善多少；[epiplexity](epiplexity.md)刻画计算受限时描述数据所需的结构；压缩进展比较新旧压缩器在同一历史上的表现，把已经发生的学习转成未来经验选择的依据。

本文提出框架、形式化并回顾已有实现。上述循环可以使用固定的压缩器更新规则。
