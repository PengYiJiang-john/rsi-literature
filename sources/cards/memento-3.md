# Memento 3 如何用世界模型改进下一轮交互

探索陌生游戏时，系统只做过少量动作，却需要选择下一步。Memento 3 从经历中总结环境规律，预测尚未尝试的行动会产生什么后果；新执行结果再推动规则修订。

## 把经验写成规则和可执行模型

系统从交互记录中提取自然语言规则，组成“规则书”，再转成可执行的世界模型。模型根据状态与行动预测后果，规划过程据此选出下一步，到真实环境执行。

实际结果与预测不一致时，系统修改规则及程序。修订经过两项检查：程序有没有偏离文字规则，以及程序能否重现已有记录中的状态变化。规则书与可执行表示跨轮更新，基础语言模型、修订流程和验证办法保持固定。

## 规则书能否减少外部尝试

作者删除规则书形成对照，保持执行框架、验证器、基础模型和推理强度等条件一致。在所选的消融游戏中，两组都完成任务，保留规则书的版本使用更少的环境动作，支持规则书对交互效率的帮助。游戏案例进一步展示了具体规则怎样随反馈改变。

## 从历史一致走向新证据

两个模型可能同样解释历史，却对未尝试行动给出不同预测。执行能区分预测的行动，才有机会发现哪种解释不对；过早依赖某个模型规划，也可能避开这些尝试。

这与 [模型批判](bayesian-model-criticism.md) 相接：用已有记录修订解释，再通过新证据检验解释。Memento 3 将前一步落实为可运行的规则修订，并让修订后的模型参与下一轮行动。
