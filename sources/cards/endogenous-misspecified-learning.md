# 内生错设学习 哪些自洽状态能成为长期结果

[Berk–Nash 均衡](berk-nash.md)允许一种信念支持当前行动，但学习者还会继续更新信念。Fudenberg、Lanzani 与 Strack 研究：更新一直进行时，什么样的行动才能长期保持不变？

## 同样拟合经验的模型 可能建议不同的行动

多个模型可能具有相同的平均预测损失，却给出不同预测、推荐不同的行动。后续样本会改变学习者在这些模型之间分配的信任，行动也可能随之变化。

普通 Berk–Nash 条件要求存在一种信念：它只相信最佳拟合模型，并使当前行动最优。要说明行动在持续学习中稳定，还需检查主体转而相信另一个同样拟合得好的模型时，原行动是否仍然最优。

## 稳定行动必须经得起信念重新分配

记 a* 为可能稳定下来的行动，Θ*(a*) 为反复选择它时、最符合所得反馈的模型集合。μ 是学习者在这些模型上分配的信念概率，rθ(a) 是模型 θ 对行动 a 的预期收益。论文给出的必要条件是：

```math
a^*\in\arg\max_a\int r_\theta(a)\,\mu(d\theta)
\quad\text{对所有满足 }\mu(\Theta^*(a^*))=1\text{ 的 }\mu.
```

这就是 uniform Berk–Nash 条件：无论怎样在最佳拟合模型之间分配概率，原行动都最优。最佳解释之间的后验权重变化，因而不会使原行动失去最优性。

该结论针对主观模型类固定、行动和结果有限的贝叶斯决策问题：如果最优学习行为收敛，极限必须满足这个条件。论文还给出严格均衡在适当初始信念下成为长期结果的条件；一般轨迹是否收敛则需另行判断。

## 从当前自洽到长期稳定

均衡解释“主体目前为什么不改行动”；这篇论文进一步检查“它继续学习后，为什么仍能不改行动”。关键是最佳拟合解释之间的信任仍可能变化。

这为 RSI 提供了固定机制下的动态基线。扩展模型类、修改观测工具或改变更新方法，会改变可用解释或学习过程，原有稳定条件也需要随之重新检查。
