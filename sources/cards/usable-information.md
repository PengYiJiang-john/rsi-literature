# 可用信息 同一份证据为何对不同学习者作用不同

一份数据包含某个规律，不代表任何模型都能读出它。一个简单示意是：两个输入各自独立、等概率取 +1 或 −1，结果由它们的乘积决定，而模型只能对给定特征作线性读出。直接给两个输入与先算出乘积再交给模型，使用的是同一份证据，却可能产生完全不同的预测效果。Xu 等用“可用信息”描述这种差别。

## 先固定谁在使用信息

设 X 是输入，Y 是要预测的结果，𝒱 是允许使用的预测模型集合。模型 f 看到 X 后，为 Y 的各个可能取值分配概率。f(X)(Y) 表示它给实际出现的结果所分配的概率。

论文用对数损失评价预测。模型如果反复给实际发生的结果很低概率，就会付出较大的损失。比较集合中所有允许的模型，取它们能够达到的最低平均损失，得到条件 V-熵：

```math
H_{\mathcal V}(Y\mid X)
=\inf_{f\in\mathcal V}\mathbb E[-\log f(X)(Y)].
```

这里的 inf 表示这组模型损失能够逼近的最低值，期望是对数据平均。再计算不看 X 时同类模型能达到的最低损失 H𝒱(Y)，两者的差就是输入提供的可用信息：

```math
I_{\mathcal V}(X\to Y)
=H_{\mathcal V}(Y)-H_{\mathcal V}(Y\mid X).
```

这个差回答的是：允许这类模型看输入，最多能把预测改善多少？若模型族允许忽略输入，多给输入至少可以保持原来的最佳预测办法，所以差值非负。

## 计算为什么能增加可用性

仅对输入作确定性处理，不会增加它与预测目标之间的 Shannon 互信息。可是，前面的乘积示意说明，处理可以把同一规律改写成某类模型容易使用的形式。这里没有引入新证据，改变的是证据对当前预测者是否有用。

论文在合成树结构恢复等任务中比较不同信息估计方法。任务要求根据数据判断变量之间的联系，因此，估计器如何衡量关系中的信息，会影响最终恢复的结构。

## 可用多少与已经学到多少要分开

定义取的是模型族中的最佳预测表现。某次训练可能尚未找到这个模型，所以可用信息不等于当前模型已经利用的信息。当前损失离类内最优多远，是训练进度问题；换一个更强模型族后，最优值还能下降多少，是能力范围问题。

[合并阶梯](merged-staircase.md)研究训练能沿什么路径获得新特征，[压缩进展](compression-progress.md)比较一次更新前后的实际改善。它们分别研究可用信息如何被学到，以及学习已经带来多少变化。
