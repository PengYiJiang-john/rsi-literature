# Performative prediction 预测模型怎样改变下一轮数据

信用评分规则部署后，申请者可能据此调整材料，下一轮训练数据也随之改变。Perdomo 等研究这种 performative prediction：模型通过部署影响环境，重训又使用环境返回的数据。

## 重训与部署优化的区别

用 φ 表示已部署的模型参数，D(φ) 表示它引起的数据分布。θ 是准备评价的模型参数，ℓ(z; θ) 是它在样本 z 上的损失：

```math
R(\theta;\phi)=\mathbb E_{z\sim D(\phi)}[\ell(z;\theta)].
```

第二个位置决定数据来源，第一个位置决定用哪个模型计算损失。重训收集旧模型 θₜ 诱导的数据，再选择使 R(θ; θₜ) 最小的新模型。部署优化直接最小化 R(θ; θ)：换模型时，同时考虑它会产生怎样的新数据。

如果重训停在 θ*，说明 θ* 最适合 D(θ*)。另一个模型却可能改变人们的行为，并在新分布上获得更低损失。因此，稳定点与部署最优点可以不同。

## 什么条件下重训会稳定

论文要求损失的梯度对参数和样本都平滑：改变 θ 或 z，梯度的变化幅度都由常数 β 控制。损失对参数还需具有 γ 强凸性，使当前分布下的优化具有唯一、稳定的最优解。

部署引起的数据变化用 Wasserstein-1 距离衡量，即把一个分布搬成另一个分布所需的最小平均移动距离。参数每变化一个单位，分布至多变化 ε 个单位。

当 ε < γ/β 时，总体重复风险最小化收敛到唯一稳定点：这个界给出重训稳定的充分条件。“总体”指每轮准确使用分布期望；有限样本版本另需尾部条件和随迭代增长的样本量。

## 反馈怎样进入优化

[Outside the Echo Chamber](outside-echo-chamber.md)接着研究稳定与最优的差距，通过估计环境对部署的响应来优化部署风险。[Berk–Nash](berk-nash.md)则研究行动选择的证据怎样支持主观信念。

Performative prediction 把模型对数据分布的影响直接写入目标。对 RSI，评价一次修改也就需要计算它对后续反馈的影响。
