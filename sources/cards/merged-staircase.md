# 合并阶梯 简单特征怎样成为后续学习的起点

如果一个目标只在三个变量同时出现时才表现出规律，逐个查看变量可能什么也看不出来。若目标还包含单变量与两变量的规律，训练就多了逐步进入复杂结构的机会。Abbe 等研究的正是这种学习路径，而不只是网络能否表示目标函数。

## 一个目标提供起点 另一个没有

论文比较下面两种函数，其中每个输入变量独立地以相同概率取 +1 或 −1：

```math
f_{\mathrm{step}}(x)=x_1+x_1x_2+x_1x_2x_3,
\qquad
f_{\mathrm{parity}}(x)=x_1x_2x_3.
```

第一种目标包含 x₁。单看 x₁，就能发现它与输出有关；已经学到的特征又可能帮助训练识别后面的乘积项。第二种目标只有三变量乘积，单个变量或两变量乘积与输出都不相关，因而缺少同样的低阶信号。

## 合并阶梯把逐级学习写成条件

将目标写成若干非零乘积项。用 Sₖ 表示第 k 项涉及的变量集合。“合并阶梯”要求这些项可以排序，使每个新项至多引入一个此前尚未出现的变量：

```math
\left|S_k\setminus\bigcup_{j<k}S_j\right|\leq 1.
```

公式中的并集包含此前所有项已经使用的变量；集合差留下新出现的变量；竖线表示变量个数。新项可以复用多个早期项中的变量，所以它比沿着一条固定的乘积链增长更一般。

## 成立条件怎样限制结论

作者考察只依赖少量输入坐标的稀疏目标、两层网络，以及指定尺度下的批量随机梯度训练。分析借助平均场极限，用参数分布随训练的演化近似宽网络，并研究样本量随输入维数同阶增长的情形。

在这些训练和资源条件下，可学目标必须具有合并阶梯结构。反过来，具有这一结构的目标对几乎所有系数组合都可学，但某些特殊组合不在保证之内。

实验跟踪不同项被学到的先后，也展示特殊系数组合造成的退化。这里的学习困难由指定算法与资源共同决定。

## 这对理解能力增长有什么帮助

[可用信息](usable-information.md)衡量一类模型能达到的最佳预测；合并阶梯进一步问，训练是否有路走到那里。在固定架构与更新算法下，已有特征也可以改变后续学习的起点。
