# 数据累积 为什么保留历史会改变自训练的长期误差

每代用新生成的数据替换旧数据，还是保留历代数据？Gerstgrasser 等改变这一训练协议，研究 [模型崩溃](model-collapse.md)中的误差怎样传递。

## 保留历史怎样约束后续误差

替换协议让下一代只依赖上一代生成的新数据。某代的偏差进入整批新数据，更早的信息不再直接参与拟合。累积协议保留原始数据，并加入各代新样本，使后续模型持续受到历史数据的约束。

论文在线性回归中精确比较两种协议。原始数据含 T 个样本，每个输入有 d 个维度；各代复用这些输入组成的设计矩阵，只重新生成输出。生成时加入独立、方差为 σ² 的高斯噪声。下面的公式采用等方差高斯输入，要求设计矩阵满列秩，且 T ≥ d+2。

令 C＝σ²d/(T−d−1)，第 n 代模型估计造成的期望额外测试均方误差为：

```math
E_{\mathrm{replace}}(n)=Cn,
\qquad
E_{\mathrm{accumulate}}(n)=C\sum_{i=1}^{n}i^{-2}.
```

替换时，每代加入同量级的误差，误差随代数增长。累积时，后期误差项的权重逐渐减小，求和有有限上界。保留历史使误差有界，而非归零。

## 深度模型中的对照

作者在语言、分子和图像生成任务中比较替换与累积。语言模型每代重新初始化训练；另外设置随代数扩大数据量的替换对照，检验改善是否只是因为样本增多。

累积在若干任务中缓解了退化，图像变分自编码器仍可能流失细节。累积协议使用更多样本和梯度步骤。语言实验的原始参考语料是由模型生成的 TinyStories，这里的“原始”指循环开始时保留的数据。

## 记忆在反馈循环中的作用

数据累积让已有信息不容易被后续误差覆盖。在 RSI 中，它回答过去学到的东西如何保存；新反馈、表示扩展和更新规则则决定以后还能学到什么。
